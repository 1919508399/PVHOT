
【光伏行业翻译规则 — 本平台专注于光伏产业链与配套储能，严格遵守】

1. 歧义默认值：以下词在中文有非光伏歧义，**一律按光伏含义翻译**：
   - Cell / cells = 电池片（不是"电池""细胞"；储能电芯写"电芯"）
   - Module / modules = 组件（不是"模块"；软件语境才译"模块"）
   - Wafer = 硅片（不是"晶圆"）
   - Ingot = 硅棒；Brick = 硅锭
   - Polysilicon = 多晶硅（口语可写"硅料"）；Granular polysilicon = 颗粒硅
   - Ingot pulling = 拉晶；Czochralski / CZ = 直拉（保留 CZ）
   - Wafering / Slicing = 切片；kerf loss = 切片损耗
   - Busbar = 主栅；0BB = 无主栅（保留 0BB）
   - Ribbon = 焊带（不是"丝带""缎带"）
   - Silver paste = 银浆；Silver per cell = 单片银耗
   - Encapsulant = 胶膜；EVA / POE 保留英文
   - Junction box = 接线盒；Frame = 边框；Solar glass = 光伏玻璃
   - Tracker = 跟踪支架（不是"追踪器"）；Mounting = 支架
   - String inverter = 组串式逆变器；Central inverter = 集中式逆变器；Microinverter = 微型逆变器（可简称"微逆"）
   - BOS = 系统平衡部件（保留 BOS）
   - BESS = 储能系统（保留 BESS）；PCS = 储能变流器（保留 PCS）；EMS = 能量管理系统
   - EPC = 工程总承包（保留 EPC）；IPP = 独立发电商；Developer = 开发商
   - PPA = 购电协议（保留 PPA）；LCOE = 平准化度电成本（保留 LCOE）
   - Grid parity = 平价上网；Curtailment = 弃光/限电（不是"缩减"）
   - Capacity = 产能（制造）或装机容量（电站），按上下文区分，不要一律译"容量"
   - Utilization rate = 开工率（不是"利用率"）；Operating rate 同
   - Shutdown / Maintenance = 停产检修；Restart = 复产；Ramp-up = 爬产
   - Shipment = 出货量；Inventory = 库存；Order book = 在手订单
   - Tender = 招标；Bid = 投标/报价；Award = 中标
   - Anti-dumping duty / Countervailing duty = 反倾销税 / 反补贴税（合称"双反"）
   - IRA = 通胀削减法案（保留 IRA）；Section 201 / 301 保留原样；UFLPA 保留
   - Feed-in tariff = 上网电价（历史政策可写"标杆电价"）；Capacity price = 容量电价
   - Curtailment rate = 弃光率；Consumption = 消纳（不是"消费"）
   - Green certificate = 绿证；Green power trading = 绿电交易

2. 技术路线名**一律保留英文原文**，不翻译不加中文括注：
   - PERC / TOPCon / HJT / IBC / HPBC / ABC / xBC / TBC
   - 钙钛矿写中文（Perovskite = 钙钛矿）；Tandem = 叠层
   - LPCVD / PECVD / ALD / 扩散 / 刻蚀 / 丝网印刷：工艺名保留常用写法，不要音译
   - MBB / SMBB / 0BB / 双玻 / 双面 / 半片 / 三分片：保留行业惯用写法
   - 型号与版本号一字不改（如 TOPCon 3.0、DeepBlue 5.0、Hi-MO 9、Vertex N、Tiger Neo），不扩写成"第几代"

3. 中国厂商**用官方中文品牌名**（首次出现可双标），不要生造译名：
   - 隆基绿能（LONGi）/ 晶科能源（JinkoSolar）/ 天合光能（Trina Solar）/ 晶澳科技（JA Solar）
   - 通威股份 / 协鑫科技（GCL）/ 协鑫集成 / TCL中环 / 爱旭股份（ABC）/ 阿特斯（Canadian Solar）
   - 东方日升 / 正泰新能（Astronergy）/ 一道新能（DAS Solar）/ 华晟新能源（Huasun）
   - 阳光电源（Sungrow）/ 华为数字能源（FusionSolar）/ 锦浪科技（Solis）/ 固德威（GoodWe）/ 上能电气（Sineng）
   - 福斯特 / 福莱特 / 信义光能 / 迈为股份 / 捷佳伟创 / 奥特维 / 中信博（Arctech）
   - 海外公司保留原名：First Solar / Hanwha Qcells / Maxeon / SolarEdge / Enphase / Nextracker / Wacker / OCI / REC / Meyer Burger

4. 数字与单位**一字不改**保留原口径：
   - 价格：元/W、$/W、元/公斤、$/kg、元/片、元/平方米、元/Wh、$/kWh
   - 规模：MW、GW、MWh、GWh、万吨、万吨/年
   - 效率：%、mV、mA/cm²、cm²（电池面积必须保留，不要省略）
   - 金额：亿元、亿元/年、$、€ 原样保留，不要把 "$1.2B" 改写成"十亿美元级"
   - 不要把 "降本 0.02 元/W" 改写成"成本大幅下降"

5. 代码 / URL / 命令 / 表格数字一字不改；反引号内容不翻译。
